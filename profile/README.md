# Sitebulb

**Sitebulb is a technical SEO website auditor, available on Desktop and in the Cloud, that turns crawl data into prioritised, explained issues — and now lets AI assistants read your audits directly through the Sitebulb MCP.**

Sitebulb crawls your site, flags problems as categorised **Hints** that explain what's wrong and why it matters, and visualises structure with crawl maps. With the Sitebulb MCP connected, Claude, ChatGPT or any MCP-capable client can query your finished audits, and Sitebulb Skills wrap that data in repeatable SEO workflows.

## What Sitebulb does

- **Audit** — crawl any site (with JavaScript rendering) and get prioritised Hints, not raw data dumps
- **Visualise** — crawl maps, link-equity scores and reports built for showing clients what's going on
- **Connect** — a read-only MCP for Sitebulb Cloud and Sitebulb Desktop, authenticated with your Sitebulb sign-in, on every plan including the free trial
- **Automate** — Sitebulb Skills for triage, client-ready audit documents, change-since-last-crawl comparisons, release-day regression checks, and pushing findings into Jira, Linear, Asana, Monday or ClickUp
